# Joel D’Silva

I’m a **product designer who builds**.

I turn complex, data-rich systems into clear products—and stay close enough to implementation to help teams ship, learn, and improve. I’m based in Lisbon and currently work as a Senior Interaction Designer at Nokia on cloud-native 5G B2B software.

My best work sits where interaction design, systems thinking, research, and engineering meet.

## Building now

- **[Screen Spec MD](https://github.com/joeldfs/screen-spec-md)** — a Figma plugin that turns frames into compact Markdown/YAML specifications for coding agents. Offline, deterministic, and open source.
- **[Lattice](https://lattice.tinyprd.com/)** — a learning and memory product exploring durable review, retrieval, and AI-assisted study. Currently in invite-only beta.
- **[TinyPrd](https://tinyprd.com/)** — my independent product studio for small, focused software.
- **[Figma Community tools](https://www.figma.com/@joeldsilva)** — six published plugins and widgets for planning, data generation, action replay, diagrams, layout iteration, and design-to-code handoff.
